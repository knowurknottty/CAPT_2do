## Immediate strategy

1. Shared OS is the short-fuse target: reuse CAPT Node/MCP/Arena concepts, but only if a clean qualifying build can be produced without derailing higher-value work.
2. Treat Amazon Developer as the primary serious submission. The Alexa+ self-hosted MCP path is unusually aligned with existing CAPT assets, and Ring supplies a natural humanitarian/accessibility/caretaking angle.
3. Run Hack Apertus as the sovereignty/trust/open-intelligence submission and use CAPTsec Red/Blue/Purple plus multilingual provenance work to differentiate it.
4. Build one reusable humanitarian core — crisis intake, multilingual triage, provenance, geospatial coordination and governed agent execution — then adapt its presentation/integration layer for Amazon, Nebius and OpenCV rather than creating unrelated hackathon toys.
5. RevenueCat is worth entering only with a genuinely new mobile product that Inversion Labs would want to ship anyway.
